Floating Chat with any A2A agent

The chat in the corner talks to the agent whose card this page names. Its look is set below, every part of it, and its contact form is sent to this page's own code. Nothing here uses a backend of inHotel's.

To try it on your computer, start the echo agent and the chat (npm run agent:echo and npm run dev), then serve this folder over http, for example with python3 -m http.server -d examples 8080, and open http://localhost:8080/any-agent.html. A page opened as a file cannot frame the chat.
